Montar a base

Os jogos vem direto do CDN da NBA. Nao precisa rodar nada fora daqui.

Caminho recomendado: publicar o games.json pelo GitHub Actions. O servidor busca o CDN sem restricao e o app so le o arquivo — atualiza sozinho todo dia, sem ninguem mexer.
Aqui no navegador: depende do CDN da NBA liberar CORS. Se der "Failed to fetch", e bloqueio do lado deles.
Como publicar (uma vez so)

1. Suba brejo.html, build_data.py e .github/workflows/update.yml num repositorio
2. Ligue o GitHub Pages nas configuracoes
3. Aba Actions → "Atualizar base" → Run workflow
4. Pronto: todo dia as 9h ele refaz o games.json sozinho
